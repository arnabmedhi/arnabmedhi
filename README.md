### Hi, I'm Arnab, a doctor at AIIMS Rishikesh. I build AI for hospitals that still run on paper.

**Discharge Desk** · live  
Turns phone photos of handwritten case files into each unit's official discharge summary.  
1,135 cases run, 1,095 summaries delivered, 70+ doctors, five departments, ten units (as of 16 October 2026).  
40–60 minutes by hand, under 10 minutes with Discharge Desk.  
[Website](https://wardos.in) · [About the project](https://github.com/arnabmedhi/discharge-desk)

**WardOS** · coming next
